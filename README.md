# Retail-Analysis-Dashboard-using-AI


An interactive, single-file HTML dashboard for exploring retail store transaction data.
Built with **Chart.js**, **SheetJS**, and vanilla JavaScript — no build step, no backend, no dependencies to install.

![Dashboard Preview]()

---

##  Features

| Category | Details |
|---|---|
| **5 KPI Cards** | Total Revenue · Transactions · Units Sold · Avg Order Value · Top Store |
| **5 Interactive Visuals** | Revenue Trend · Revenue by Product · Revenue by Store · Payment Mix · Day × Time-of-Day Stack |
| **Slicers** | Store ID · Location · Product · Payment Type · Store Manager |
| **Timeline** | Clickable month chips + custom date range picker |
| **Upload** | Drag-and-drop or browse for `.xlsx`, `.xls`, or `.csv` files |
| **Theme** | Modern dark glassmorphism with gradient accents |
| **Responsive** | Works on desktop, tablet, and mobile |
| **Zero install** | Just open `index.html` in a browser |
